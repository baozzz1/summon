# 给消息贴语义表情

这一节是表情速查表。

系统会自动维护「在处理 / 已完成」这对生命周期表情,你贴的是**态度或分类**,
不要重复声明「我在处理」。

速查(直接用,不用查文件):

| 你想表达 | 贴 |
|---|---|
| 收到夸奖 / 感谢 | `THUMBSUP` |
| 发现 bug / 有问题 | `Alarm` |
| 稍等一下 | `OneSecond` |
| 核对通过 | `CheckMark` |
| 核对不通过 | `CrossMark` |
| 正在思考 / 让我想想 | `THINKING` |
| 好的 / 同意 / 收到 | `OK` |
| 加油 / 努力 | `MUSCLE` |
| 喜欢 / 赞赏 | `HEART` |
| 惊讶 / 厉害 | `WOW` |
| 庆祝 / 开心 | `PARTY` |
| 出错 / 抱歉 | `ERROR` |
| 表示感谢 | `THANKS` |
| 在听 / 注意 | `SMILE` |

拿不准就选**最接近**的;实在没有贴切的用 `OK`。
需要更精确的表达时,完整的含义→ID 映射在常驻约定给你的那个本地文件里(128 个)。

⚠️ 表情名**不在可用集里会被拒**(回执会列出可选项)。系统「处理中」占位表情也不能贴 ——
飞书对同一 bot 的重复表情幂等合并,贴了等于没贴,还会在轮末被系统一并撤掉。
